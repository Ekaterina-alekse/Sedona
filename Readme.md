## 📖 О проекте

**Седона** — небольшой городок в Аризоне. Этот проект представляет собой двухстраничный сайт с описанием города и каталогом гостиниц.

🔗 **Открыть сайт**: [https://github.com/Ekaterina-alekse/Sedona](https://Ekaterina-alekse.github.io/Sedona/)

## 🎯 Функциональность

### Главная страница
- Приветственный блок с логотипом
- 5 карточек с преимуществами города
- 3 карточки сервисов (жильё, еда, сувениры)
- Блок с призывом найти гостиницу
- Форма подписки на рассылку
- Подвал с соцсетями, телефоном и ссылкой на HTML Academy

### Страница каталога
- Фильтры: инфраструктура, тип жилья, цена (с ползунком)
- Сортировка: по цене, популярности
- Карточки гостиниц с рейтингом и звёздами
- Пагинация
- Форма подписки

### Модальное окно
- Поиск гостиницы: даты, количество взрослых и детей
- Кнопки увеличения/уменьшения количества гостей
